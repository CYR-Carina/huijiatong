# 惠家通 — 乡村家庭智能服务 Agent

> 一个 Agent，服务整个农村家庭——学生问资助，老人防诈骗，全家享便利。

**在线体验**：[https://cyr-carina.github.io/huijiatong/](https://cyr-carina.github.io/huijiatong/)

## 核心功能

| 功能 | 说明 |
|:-----|:-----|
| 💰 资助政策问答 | 助学贷款、助学金、奖学金、绿色通道、勤工助学 |
| 📋 条件自测 | 输入家庭情况 → 智能推荐匹配资助项目 |
| 🛡️ 诈骗识别劝阻 | 分析可疑电话/短信，判断是否为诈骗并警示 |
| 🏥 健康科普 | 高血压/糖尿病管理、日常养生建议 |
| 👴 养老政策查询 | 养老金、医保、高龄补贴、社保卡办理 |

## 技术栈

- **前端**：原生 HTML/CSS/JS，单文件零依赖
- **大模型**：豆包 / 智谱AI / 硅基流动（三级回退）
- **语音**：浏览器 Web Speech API（ASR + TTS）
- **知识库**：双知识库（资助政策库 + 银龄关怀库）
- **部署**：GitHub Pages

## 快速开始

```bash
# 本地运行
cd 惠家通
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

不配置 API Key 也能用，会以本地知识库模拟回复。配置后回答更准确。

## 在 Trae IDE 中使用

在 Trae IDE 中打开本项目，AI 对话输入 `@惠家通` 即可调用智能体，支持知识问答和项目开发。

## 安全边界

- 不编造政策，不知道就引导拨打 010-66097980
- 不做医疗诊断，只做科普，引导就医
- 涉及金额标注"以当年官方政策为准"
