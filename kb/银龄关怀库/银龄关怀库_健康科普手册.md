# 老年人健康科普手册

## 一、高血压管理

### 1.1 什么是高血压
- 收缩压（高压）≥140mmHg
- 或舒张压（低压）≥90mmHg
- 常见症状：头晕、头痛、耳鸣、失眠

### 1.2 日常注意事项
- 🔴 少吃盐：每天不超过5克（大约一啤酒瓶盖的量）
- 🔴 少吃油腻食物：肥肉、动物内脏要少吃
- 🔴 戒烟限酒：烟能戒就戒，酒尽量少喝
- 🟢 多吃蔬菜水果：每天至少半斤蔬菜
- 🟢 适量运动：每天散步30分钟，微微出汗就好
- 🟢 保持心情愉快：不要生气着急
- 🟢 定期测量血压：建议每周量2-3次

### 1.3 用药提醒
- 遵医嘱按时吃药，每天固定时间吃
- **不要自己停药或减药**，即使感觉好了也要继续吃
- 忘记吃药不要补双倍，按下一次时间吃就行
- 注意药物副作用，头晕、脚肿要及时告诉医生
- 定期去医院复诊，让医生调整药量

## 二、糖尿病管理

### 2.1 什么是糖尿病
- 血糖水平持续升高
- 常见症状：多饮、多食、多尿、体重减轻

### 2.2 日常注意事项
- 🔴 少吃甜食、含糖饮料：白糖、红糖、蜂蜜都要少吃
- 🔴 少吃油腻食物：油条、肥肉要少吃
- 🔴 控制主食量：每餐米饭不超过一碗
- 🔴 不要吃太多水果：选择苹果、柚子等含糖量低的
- 🟢 多吃蔬菜：特别是绿叶菜
- 🟢 规律运动：饭后散步30分钟
- 🟢 控制体重：不要太胖
- 🟢 定期测血糖：建议每周测2-3次

### 2.3 用药提醒
- 按时服药或注射胰岛素，不能自己停药
- **随身携带糖果或饼干**，防止低血糖
- 出现头晕、心慌、出冷汗时，可能是低血糖，赶紧吃颗糖
- 定期去医院复查血糖、检查并发症

## 三、冠心病管理

### 3.1 什么是冠心病
- 心脏供血不足引起的心脏病
- 常见症状：胸痛、胸闷、气短、活动后加重
- ⚠️ 如果胸痛持续15分钟以上不缓解，立即拨打120

### 3.2 日常注意事项
- 🔴 少吃盐和油腻食物
- 🔴 戒烟限酒
- 🔴 避免剧烈运动和情绪激动
- 🟢 规律服药，不要自行停药
- 🟢 随身携带急救药物（如硝酸甘油）
- 🟢 定期复查心电图

### 3.3 急救提醒
- 胸痛发作时立即坐下休息
- 舌下含服硝酸甘油（如有）
- 如果5分钟不缓解，立即拨打120
- 不要自己走去医院，等救护车

## 四、骨质疏松

### 4.1 什么是骨质疏松
- 骨头变脆变薄，容易骨折
- 常见症状：腰背疼痛、身高变矮、驼背
- 老年女性更容易得

### 4.2 日常注意事项
- 🟢 多晒太阳：每天晒15-20分钟，帮助身体合成维生素D
- 🟢 多喝牛奶、吃豆制品补钙
- 🟢 适量运动：散步、太极，增强骨骼
- 🔴 防跌倒：卫生间铺防滑垫，走廊装扶手
- 🔴 少喝浓茶、咖啡，影响钙吸收

### 4.3 补钙建议
- 每天喝1-2杯牛奶
- 多吃豆腐、虾皮、深绿色蔬菜
- 如需吃钙片，咨询医生
- 同时补充维生素D，帮助钙吸收

## 五、白内障

### 5.1 什么是白内障
- 眼睛的晶状体变浑浊，看东西模糊
- 常见症状：视力下降、看东西有重影、怕光
- 是老年人最常见的眼病

### 5.2 日常注意事项
- 🟢 外出戴帽子或墨镜防晒
- 🟢 多吃富含维生素的食物（胡萝卜、玉米）
- 🔴 不要乱滴眼药水
- 🔴 不要相信"药物能治好白内障"，手术是目前唯一有效治疗方法

### 5.3 手术提醒
- 白内障手术技术成熟，不用害怕
- 一般住院1-2天即可
- 医保可以报销部分费用
- 视力影响日常生活时就该考虑手术，不要等到"看不见"

## 六、脑梗（中风）康复

### 6.1 什么是脑梗
- 脑血管堵塞，导致脑组织损伤
- 常见症状：突然口歪眼斜、说话不清、一侧手脚无力
- ⚠️ 出现上述症状立即拨打120，越早治疗恢复越好

### 6.2 快速识别口诀（120原则）
- **1看**：看一张脸，是否不对称、口角歪斜
- **2查**：查两只手臂，是否一侧无力
- **0听**：听说话，是否口齿不清
- 只要出现任何一个，立即打120

### 6.3 康复注意事项
- 🟢 坚持做康复训练，越早越好
- 🟢 控制血压、血糖、血脂
- 🟢 家人要多鼓励、多陪伴
- 🔴 不要自行停药
- 🔴 不要相信"偏方能治中风"

## 七、日常养生建议

### 7.1 饮食原则
- 三餐定时定量
- 粗细搭配
- 营养均衡
- 细嚼慢咽

### 7.2 运动建议
- 选择适合自己的运动：散步、太极、广场舞
- 运动时间：上午9-10点，下午4-5点
- 运动强度：以微微出汗为宜
- 注意安全，避免跌倒

### 7.3 生活习惯
- 保证充足睡眠
- 不要熬夜
- 保持室内通风
- 注意个人卫生

## 八、常见不适处理

### 8.1 头晕
- 立即坐下或躺下休息
- 缓慢变换姿势
- 喝水
- 如果频繁发作，及时就医

### 8.2 胸闷气短
- 停止活动，休息
- 保持室内通风
- 解开衣领
- 如果持续不缓解，立即拨打120

### 8.3 关节疼痛
- 注意保暖
- 适当活动
- 避免过度劳累
- 必要时就医检查

- 慢性病患者要定期复查，不要只吃药不检查
